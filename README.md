# MIS444 – Predictive Analytics in Business
## Diabetes Risk Prediction Using Classification Models

### Project Overview
This project applies classification-based predictive analytics to identify whether a patient is likely to have diabetes using demographic, medical, and lifestyle data. The goal is to support healthcare decision-making through early risk detection.

### Dataset
- Source: Kaggle – Diabetes Prediction Dataset
- Records: 100,000 patients
- Target Variable: Diabetes (0 = No, 1 = Yes)

### Models Used
- Logistic Regression
- Decision Tree
- K-Nearest Neighbors (KNN)
- Random Forest
- Neural Network

### Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC

### Tools & Libraries
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
